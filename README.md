## 🚀 Deskripsi Proyek (Project Description)

**Anime-Verse** adalah sebuah aplikasi mobile yang dikembangkan menggunakan **Flutter**. Tujuan utama aplikasi ini adalah menyediakan *platform* yang mudah digunakan untuk mencari dan membaca **sinopsis berbagai anime**.

Pengguna (user) memiliki kemampuan untuk:
* Melihat daftar sinopsis anime.
* Membaca sinopsis secara lengkap.
* **Menambahkan** anime yang disukai ke dalam daftar **'Favorite'** mereka.

Aplikasi ini dibuat sebagai [Sebutkan tujuan tugas/kuliah jika ada, misal: Tugas Akhir Mata Kuliah Pemrograman Mobile].
